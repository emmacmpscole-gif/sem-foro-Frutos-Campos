#Proyecto semaforo
## 1. Requerimientos funcionales 
*RF1:* El semáforo debe encender las luces roja, amarilla y verde para regular el tránsito.
*RF2:* El semáforo debe cambiar las luces automáticamente siguiendo una secuencia programada.
*RF3:* La luz roja debe indicar a los conductores que deben detenerse.
*RF4:* La luz amarilla debe advertir a los conductores que se aproxima un cambio de señal.
*RF5:* La luz verde debe indicar a los conductores que pueden avanzar, siempre que sea seguro.
