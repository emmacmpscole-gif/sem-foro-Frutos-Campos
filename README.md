# Proyecto semaforo
## 2. Requerimientos no funcionales
**RNF1:** El semáforo debe funcionar de manera continua y confiable.
**RNF2:** Las luces deben ser claramente visibles durante el día y la noche.
**RNF3:** El sistema debe resistir las condiciones climáticas, como la lluvia, el viento y las altas temperaturas.
**RNF4:** El semáforo debe contar con un sistema eléctrico seguro y protegido.
**RNF5:** El sistema debe recibir mantenimiento periódico para garantizar su correcto funcionamiento.
## 3. Historias de usuario
**HU1:** Como conductor, quiero ver la luz roja para saber cuándo debo detenerme y evitar accidentes.
**HU2:** Como conductor, quiero ver la luz verde para saber cuándo puedo avanzar de forma segura.
**HU3:** Como conductor, quiero ver la luz amarilla para estar preparado ante un cambio de señal.
**HU4:** Como peatón, quiero que el semáforo regule el tránsito para poder cruzar la calle con mayor seguridad.
**HU5:** Como autoridad de tránsito, quiero que el semáforo funcione correctamente y tenga mantenimiento para mantener el orden y la seguridad vial.
